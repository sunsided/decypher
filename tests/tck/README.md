# openCypher TCK projection

`TCK_SYNTAX.jsonl` is a syntax-only projection of the official openCypher
Technology Compatibility Kit (TCK), release **2024.3** (opencypher/openCypher
commit `677cbafabb8c3c5eed458fd3b1ec0daec8d67d23`). Each `query` record holds
one Cypher query from the TCK feature files and whether a parser should accept
or reject it; `occurrence` records link queries to their scenarios and to any
error the TCK expects.

The file was generated by the `xtask tck` tooling of
[a-poor/open-cypher](https://github.com/a-poor/open-cypher) and is vendored
unmodified from commit `8a3b1cedd997eb83d9fdaacb96d5256a6503a198`
(`spec/generated/TCK_SYNTAX.jsonl`, SHA-256
`bfc514dcc70c8a55cc35407d91ef6b62643435cd203a5d619d77d2253203dd1c`).

see `LICENSE` and `NOTICE` in this directory. These files are not covered by
the crate's own licenses and are excluded from the published crate.

The pinned release and projection source are recorded in `UPSTREAM.toml`;
the `Upstream openCypher release` workflow checks monthly whether a newer
openCypher release exists and fails if so.

`tests/tck.rs` runs every query through `parse`, a print/re-parse round trip,
and `analyze`. `known_failures.txt` lists the current gaps; regenerate it with
`TCK_BLESS=1 cargo test --test tck`.
